# 第四章：实验验证与结果分析重构设计方案

## 1. 核心设计变更 (Core Changes)
- **挑战定性**：将此前模糊的描述统一修订为“**类别不平衡（Class Imbalance）**”。
- **实验分布梯度**：
    - **均衡基准任务**：二分类任务（保持约 1:2.4）与 USTC 多分类任务（保持约 1.69:1），用于验证模型的基础表征上限。
    - **不平衡挑战任务**：MTA 与 MFCP 数据集，样本分布统一调整至 **10:1**（最大类:最小类），用于验证 Stacking 决策层对**类别不平衡**的纠偏能力。
- **章节逻辑**：将原有的分散小节重构为三个大型综合实验项（实验一、实验二、实验三），分别对应技术方案的三层架构（表征层、融合层、决策层）。

- **子项 B：时序分支消融** —— 对比分层序列表示与扁平字节序列在处理长会话时的抗稀释能力。通过 **图 4.3** 展示性能随长度变化的趋势。

### 4.4 实验三：Stacking 集成决策优化与类别不平衡韧性测试
- **目标**：验证决策层针对类别不平衡场景的纠偏与仲裁能力。
- **子项 A：Stacking 有效性与可解释性** —— 对比 "Cross-Attention" 与 "Cross-Attention + Stacking" 增强模型。通过 **图 4.8** 统计少数类召回率提升，利用 **图 4.7** 分析元特征贡献度。
