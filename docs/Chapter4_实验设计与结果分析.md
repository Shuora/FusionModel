# 第四章 实验设计与结果分析

本章旨在全面评估本文提出的“基于特征融合的加密恶意流量检测模型”（即深度融合了 MobileViT 空间图像分支与 CharBERT 时序文本分支的双分支网络架构）的有效性与先进性。首先，将详细介绍实验所依赖的软硬件环境、数据集构成及其在多模态输入下的预处理重构方法；其次，阐述评估不平衡数据分类性能所使用的核心评价指标；最后，通过在多分类任务上的基线模型消融对比、多集成学习器（Meta-learners）性能评估，以及针对易混淆通信家族的定向校正分析，验证所提模型在实际恶意流量检测场景中的各项优势。

## 4.1 实验环境与数据集构建

### 4.1.1 实验环境设置

为保障模型在处理大规模加密网络数据流时具备充足的算力支持与稳定性，本实验构建在 Linux 操作系统之上，模型核心算法使用 PyTorch 深度学习框架进行开发与训练。针对双分支特征融合及其后续的 Stacking 集成学习机制，实验代码深度整合了 `Transformers`、`XGBoost`、`LightGBM` 和 `CatBoost` 等主流算法库。

在模型训练的寻优策略上，考虑到多模态网络的复杂性，实验采用了带有权重衰减机制的 AdamW 优化器（`weight_decay=1e-4`），并结合梯度裁剪（`grad_clip_norm=1.0`）以防止在处理噪声流量数据时出现梯度爆炸。学习率调度采用了验证集指标驱动的衰减策略（`ReduceLROnPlateau`，衰减因子 `factor=0.5`，最低学习率 `min_lr=1e-6`），配合带动态方向解析（`auto` 模式）且耐心轮次设定为 8 的早停（Early Stopping）机制，最大程度避免了模型陷入局部最优或发生严重过拟合。

### 4.1.2 实验数据集选择

为全面验证本文双分支融合模型在不同维度的加密流量分析场景下的泛化能力与分类精度，本实验选取了四个公开权威的数据集，并将其重构为四个相互独立的实验任务：

1. **二分类任务 (Binary Benign vs Malicious)**：该任务通过整合 `ISCX-VPN-NonVPN-2016`（作为良性流量代表）以及 `USTC-TFC2016`、`MTA` (Malware-Traffic-Analysis.net) 和 `MCFP` (Malware Capture Facility Project) 的恶意流量部分，构建全局范围的黑白流量鉴别场景。
2. **USTC-TFC2016 多分类任务 (USTC Multiclass)**：使用原始抓包文件的名称作为细粒度类别标签，验证模型在常规公开多分类基准上的特征提取与区分能力。
3. **MTA 多分类任务 (MTA Multiclass)**：提取 MTA (Malware-Traffic-Analysis.net) 库中的多种恶意家族（包含 IcedID 等复杂木马变种），重点测试模型对复杂恶意软件通信行为的特征提取能力。
4. **MCFP 多分类任务 (MCFP Multiclass)**：该数据集（在本实验工程实现中标记为 MFCP）包含由 Stratosphere 实验室捕获的 Artemis、Cobalt、Dridex、PUA、Trickbot、Ursnif 等多类极具伪装性的恶意家族。为保证实验与国际前沿研究（如 MVTBA）具有严格的可比性，针对 MTA 与 MCFP 任务，本文在数据切分阶段启用了 `paper_mvtba` 的固定目标抽样分布配置，确保了模型在真实的类别极度不均衡场景下能够获得客观的评估。

### 4.1.3 数据预处理与重构

为了满足本模型中“图像-时序”双分支网络对多模态输入的特殊需求，本文设计并实现了一套健壮的加密流量预处理机制。预处理流程分为会话提取与模态映射两个阶段：

1. **会话级提取与截断容错 (Session Splitting)**：首先通过解析原始 `.pcap` 与 `.pcapng` 抓包文件，将离散的数据包按网络五元组重组成会话级（Session）的二进制字节流。在工程实现上，本文特别针对实际网络环境中常见的尾部残缺数据包进行了容错处理，保留了已读取的有效前置特征，最大化了不完整抓包的可用数据规模。
2. **时序序列与图像空间特征映射**：
   - **时序分支 (CharBERT)**：截取会话数据流前部的关键字节（包含 SSL/TLS 握手交互特征及部分应用层载荷），作为细粒度的字节级（Byte-level）时序序列输入至 CharBERT 编码器。
   - **图像分支 (MobileViT)**：将经过清洗的二进制会话负载重塑为二维矩阵，并映射生成 RGB 三通道图像（Image Data），以供 MobileViT 分支利用其全局感受野进行空间纹理特征提取。

## 4.2 评价指标选取

在加密流量分类（特别是恶意家族细分）场景中，由于各类恶意软件的活跃程度差异巨大，数据集天然存在严重的长尾分布问题（Class Imbalance）。在此种数据分布下，单一的准确率无法客观反映模型对少数攻击类别的捕获能力。因此，本文除了常规的准确率（Accuracy, Acc）外，引入了宏平均 F1 分数（Macro F1-Score）作为验证模型鲁棒性的核心判定指标。评估体系定义如下：

- **准确率 (Accuracy, Acc)**：模型正确分类的样本数占整体验证集总样本数的比例。
- **精确率 (Precision, P)**：模型预测为某一恶意类别的样本中，实际确实属于该类别的比例，反映了模型的误报率控制水平。
- **召回率 (Recall, R)**：真实为某一恶意类别的样本中，被模型正确检出并归类的比例，反映了模型的漏报率控制水平。
- **宏平均 F1-Score (Macro F1)**：计算数据集中各个类别的 F1 分数后求其算术平均值。F1-Score 作为精确率和召回率的调和平均数，能兼顾两者的平衡。Macro F1 不受限于各类别样本的绝对数量差异，在处理如 Trickbot 家族样本庞大而 Cobalt 家族样本稀缺的极端不平衡任务时，能够更加严苛且客观地反映模型对少数类的检测性能界限。

## 4.3 基线融合模型性能评估

为直观展示本文特征融合机制的初始性能底限，本节首先对仅依赖 Attention 加权融合的基础模型（Base Fusion Model）在难度最高的 **MCFP 多分类任务** 上的表现进行分析。

模型超参数设定如下：在训练阶段，启用标签平滑（`label_smoothing=0.03`）与 Focal Loss（`focal_gamma=1.5`），同时叠加类别加权采样损失（`weighted_sampler_loss`）以初步对抗类间失衡。初始学习率设定为 `3e-4`，批次大小为 `32`，完整训练进行 `40` 个 Epoch。

经过充分收敛，基础融合模型（Base Evaluation）在 MCFP 的 28,588 个独立验证会话上取得了以下成绩：
- **总体准确率 (Accuracy)**：79.43%
- **宏平均 F1 (Macro F1)**：76.02%

通过混淆矩阵数据深度剖析发现，尽管 MobileViT 和 CharBERT 实现了视觉纹理和序列上下文特征的优势互补，使得 Trickbot (类别 4) 的精确率达到近乎完美的 99.71%，但在部分恶意家族内部仍面临以下瓶颈：
1. **弱势类别的漏报高发**：基础模型对于类别 0 (Artemis) 和类别 1 (Cobalt) 等家族的特征抓取呈现明显短板。例如，Artemis 的召回率仅有 60.09%，而 Cobalt 的精准率和召回率均处于 60% 左右的低位（F1-score 仅为 0.665）。
2. **高度同质化家族的跨类混淆**：混淆矩阵暴露出模型在区分 Artemis (类别 0) 与 Ursnif (类别 5) 这两类通信特征极度相似的木马时，产生了显著的分类边界模糊。有多达 1638 个真实为 Artemis 的样本被错误分配至 Ursnif 家族。这说明仅凭单层的 Attention 特征组合，面对复杂多变的流量加密混淆，其泛化能力与判定边界依然不够稳固。

## 4.4 引入 Attention Stacking 的实验结果与对比分析

为突破基础网络模型的单体性能瓶颈，并彻底解决长尾分布与易混淆家族导致的准确率塌陷，本文在双分支网络的基础上，设计并实现了基于 Out-of-Fold (OOF) 的 **Attention Stacking** 集成学习机制。

该机制在推理后处理阶段提取双分支网络输出的元特征（包括文本分支概率、图像分支概率、融合联合概率，并自动拼接交叉熵、边界分类间隔 Margin 及分支预测一致性等进阶特征），随后将其馈入多个非线性树模型（Meta Learners）进行高维度的二次判别。为了避免 OOF 评估受到传统 DataLoader 采样偏置的影响，本实验针对元特征加载创新性地引入了完全确定性的数据加载器（Deterministic Meta Loader）。

### 4.4.1 多集成子模型 (Meta-learners) 性能对比

实验选取了 XGBoost、LightGBM、CatBoost 三种代表性的强基分类器作为 Meta Learners，其集成后的检测性能如表 4-1 所示：

**表 4-1 各集成学习子模型在 MCFP 任务上的性能对比**
| 模型变体 | 总体准确率 (Accuracy) | 宏平均 F1 (Macro F1) | OOF Macro F1 |
| :--- | :---: | :---: | :---: |
| 基础融合模型 (Base Model) | 79.43% | 76.02% | - |
| **+ XGBoost Stacking** | 84.33% | 81.49% | 85.42% |
| **+ LightGBM Stacking** | 84.02% | 81.56% | 85.30% |
| **+ CatBoost Stacking** | 84.27% | 80.70% | 85.23% |
| **+ Soft-Voting (多模型加权)** | **84.16%** | **81.40%** | **85.37%** |

从上表可以看出，单体 Meta Learner 在接入更丰富的元特征后，均实现了对基础模型的碾压式超越。其中 XGBoost 在整体准确率上表现最优（84.33%），而 LightGBM 在应对各类别均衡度的 Macro F1 表现上更胜一筹（81.56%），相比于基础网络，其 Macro F1 飙升了约 **5.5 个百分点**。

### 4.4.2 加权软投票机制 (Soft-Voting) 的有效性

为进一步消除单一树模型在构建分类边界时的随机性偏差，本研究融合了多个可用 Meta Learner 的预测输出，执行加权软投票（Soft-Voting）。权重并非简单平均，而是自适应地提取各模型在 OOF 阶段测得的 Macro F1 置信度得分。

加权软投票后的最终网络（Soft Voting Model）输出了极其均衡稳健的结果（Acc: 84.16%, Macro F1: 81.40%）。其核心优势在于，它不仅维持了全局分类的准确性，更大幅压制了单模型的极端误报现象，在实战部署中具备更为优异的泛化韧性。如图 4.11 所示，Stacking 集成策略相比于传统的 Voting 策略，在处理极度不平衡的数据集时展现出了更强的决策鲁棒性。

### 4.4.3 任务定向校正分析与混淆矩阵改善

在分析基础模型痛点时已指出，Artemis (类别 0) 与 Ursnif (类别 5) 之间存在严重的判定重叠现象。为了针对性解决这一痛点，本文在 Stacking 集成后端创新性地加入了基于 OOF 的**动态对校正机制（Pair Correction）**：
1. **启发式 OOF 驱动寻优**：通过检索按类名解析定位的目标对（Artemis / Ursnif），利用验证集的 `pair_f1` 指标自适应搜索最佳校正强度参数 $\alpha$。
2. **温度校准与阈值调整**：校正机制针对易混淆对执行概率温度校准（例如在 Soft Voting 中，自适应测得最佳的 `pair_temperature=1.15`，`threshold=0.5`）。该机制通过柔化过高置信度（Over-confidence）并惩罚两可概率，有效地校正了原本倾斜的判定边界。

通过对比 Stacking决策纠偏前后的混淆矩阵热力图（图 4.9 与 图 4.10），可以直观地观察到分类边界的清晰化过程。在 MTA 数据集（图 4.9）中，原本集中在 Emotet 与 Qakbot 之间的模糊判定区域得到了显著压缩；而在 MCFP 数据集（图 4.10）中，Artemis 与 Ursnif 的混淆现象得到了实质性改善。

**校正前后的关键类表现改善：**
- **类别 0 (Artemis)** 的召回率实现了跨越式提升，由最初的 **60.09%** 跃升至 **74.56%**，其被错误分入 Ursnif 家族的样本数从 1638 个锐减至 1044 个。
- **类别 3 (PUA)** 的召回率由 85.24% 提升至 **92.51%**，F1-score 达到 0.8816。
- **类别 4 (Trickbot)** 等大体量家族，在获得提升的同时，依然稳固保持着高达 99.01% 的精确率与 91.61% 的 F1 分数。

这有力地证明了，通过元特征提取结合后置的任务定向二分类校正，模型不仅能在宏观上实现分类精度的拉升，更能在微观层面有效破解特定加密恶意协议间的伪装和混淆难题。

## 4.5 本章小结

本章围绕“基于特征融合的加密恶意流量检测”的核心思想，详细阐释了模型在实战环境中的部署细节、训练策略与对比验证过程。实验数据充分证明，所提的双分支网络能够有效捕捉多模态下的网络加密流特征。在此基础之上，通过引入基于 OOF 预测的 Attention Stacking 架构、多模型加权软投票机制以及自适应参数调节的任务定向校正策略，模型不仅在总体准确率（Accuracy）上实现了从 79.43% 到 84.16% 的突破，更在衡量长尾不平衡性能的宏平均 F1 分数（Macro F1）上获得了 5.38% 的大幅跃升。各项维度的显著改善，切实验证了本文模型在应对高混淆、高对抗以及极端类别不均衡的复杂加密流量检测场景中具备显著的前沿优势与工程落地价值。
